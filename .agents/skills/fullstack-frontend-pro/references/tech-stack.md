# Modern Frontend Stack (2026)

Professional frontend development in 2026 centers on type safety, performance at the edge, and AI-augmented workflows.

## Core Frameworks
- **Next.js 16+ / Remix**: The industry standard for SSR/ISR and edge-optimized routing.
- **React 20**: Leverages "React Forget" for automatic memoization and fine-grained reactivity.
- **TypeScript (Strict Mode)**: Non-negotiable for professional development.

## Styling & Components
- **Vanilla CSS / CSS Modules**: Preferred for maximum control over Liquid Glass effects.
- **Tailwind CSS 4.0**: Only when high-speed prototyping is required; use JIT features for complex filters.
- **Framer Motion 12**: Standard for fluid, Apple-style animations and scroll-triggered transitions.

## Data Fetching & State
- **tRPC / GraphQL**: For end-to-end type safety from backend to frontend.
- **TanStack Query (React Query)**: For robust caching and server-state management.
- **Zustand**: For lean, performant global client state.

## Quality Standards
- **Core Web Vitals**: LCP < 1.2s, CLS < 0.1, INP < 200ms.
- **Accessibility (WCAG 2.2)**: Support for Screen Readers, Voice Control, and Gaze-based interaction.
- **Responsive & Spatial**: Must work seamlessly on mobile, desktop, and Vision Pro (spatial environments).
