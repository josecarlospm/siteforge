# Fullstack Frontend Professional

This skill guides you through building world-class frontends that are performant, type-safe, and visually stunning (Apple-style).

## Workflow

1. **Stack Selection**: Default to Next.js 16+, TypeScript (Strict), and Framer Motion. See `references/tech-stack.md`.
2. **Component Architecture**: Build modular, accessible components with `tRPC` or `TanStack Query`.
3. **Apple Styling**: Integrate `apple-design-patterns` for Liquid Glass effects and SF Pro typography.
4. **Motion Design**: Implement Cinematic Scrolling and fluid transitions. See `references/patterns.md`.
5. **Optimization**: Ensure sub-second LCP and spatial computing readiness.

## Resources

- **Tech Stack**: Modern 2026 frontend tooling and standards. See [tech-stack.md](references/tech-stack.md).
- **Frontend Patterns**: Implementation guides for Cinematic Scrolling, Spatial Readiness, and Liquid Glass. See [patterns.md](references/patterns.md).
- **Design Foundation**: Trigger `apple-design-patterns` for visual specifics.
